This extends only the isolated operator test; it does not activate the application provider or establish public display, caching, media-download, alert or AI rights.

Require the approved connection and broker state, an explicit local inspection purpose, and approved originating-system names. Accessible metadata describes a schema, not licensed public display rights.

Require ignored output paths, restrictive file permissions where supported, no overwrite of existing outputs and no credential/token inclusion.
