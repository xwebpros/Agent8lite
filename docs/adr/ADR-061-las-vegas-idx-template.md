## Decision

1. Retain public source JSX, utility classes, gallery/search/map/filter structure and source font/color tokens in a scoped Next renderer. Import no original CRM, Directus, administrative database, SMTP or automation module. Agent/admin workspace links use Agent8lite. Register repository-owned versioned agent and brokerage draft starters in `packages/templates`; source text maps to immutable native revisions. Only an explicitly published revision is public.
2. Keep original Trestle query and projection code with source provenance/hashes. Its automatic local environment loading is isolated from the platform. Runtime invocation requires a trusted feed/site authorization and current licensed field/display/media/cache policy before and after the call. No browser credentials, raw provider records or arbitrary OData. Retention, withdrawal and address/coordinate suppression apply to all projections. Default acceptance uses conspicuously synthetic fixtures; this ADR does not activate the live feed or license map tiles.
3. Preserve the inquiry's name, email, optional phone and message. Replace source `/api/leads`/Directus/SMTP flow with a native transaction: serialize a site/form-namespaced UUID submission key; validate the current published schema and current permitted listing; compare canonical request input on replay; use CRM-owned contact/capture ports; persist the original private inquiry, safe site/feed/listing provenance and routing result; commit before returning a durable receipt. No marketing consent is inferred from an inquiry. No real email is promised by a no-delivery receipt.
4. Resolve tenant and capture authority from a reviewed server-owned site/host/source/form/feed binding. Never select the first human Owner or accept client tenant/source/assignee fields. Bindings use composite tenant foreign keys, FORCE RLS, narrow runtime grants and explicit revocation/expiry. Public capture authority is restricted to the configured site and capture command; membership, organization, entitlement, form, source and listing policy are rechecked transactionally. Agent sites use an independently authorized site member; brokerage sites use current native first-touch, geography and eligible weighted routing. Names from MLS attribution never identify platform members.
5. Add five public operations under `/v1/public/sites/{siteId}/idx-template`: content, status, listing search, listing detail and inquiry. Exact shapes live in `packages/contracts/amendments/ADR-061-idx-template.json` and are added to implementation OpenAPI only. Original blueprint contracts and existing schemas/operations remain unchanged. The source public listing projection is allowlisted, typed, policy-rechecked and marked synthetic where applicable. Source filters keep their documented bounds; page is an integer 1–100. Clients use generated platform types.
6. The source Leaflet renderer is retained behind the platform map capability seam to preserve the original map interaction. MapLibre remains the normative platform default outside this imported template. Neither public OSM demo tiles nor new commercial tiles are activated through import. Missing optional organizer/AI/market capabilities retain their layout with an explicit unavailable state; they cannot show fabricated metrics or claim completion. Private favorites/visitor/profile/listing data use server or tab memory, never persistent browser storage or service-worker caches.
