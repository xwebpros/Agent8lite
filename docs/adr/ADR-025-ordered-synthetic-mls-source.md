# ADR-025 — Stable ordered synthetic MLS source

Accepted bounded MOD-F-005/006 prerequisite on2026-10-10 after review of W07's replication-persistence proposal. Existing process-local MockMlsAdapter cannot supply durable ordering after restart. A separate server-only OrderedMockSourcePort and closed mock-replication-source-proof-v1 schema are committed before its consumer. The public MLS adapter/HTTP/event contracts remain unchanged. No database ingestion, worker registration, live source, provider credential or M5 completion is authorized by this decision.

The initial profile ordered-synthetic-v1 reads only a versioned repository-owned immutable manifest. It contains a fixed generation UUID, fixed completed watermark and1–500 explicitly identified, positively sequenced unique source changes. Entries include fixed UTC observedAt instants for incremental fixture selection, independent from nullable/tied sourceModifiedAt and timestamp-free deletions. Source change IDs and sequences never derive from cursors, content hashes, local current time or array position. Every upsert is strictly canonical and visibly synthetic; no private/raw provider fields enter the manifest. Initial fixture pricing is explicitly USD, nonfractional bedrooms and representable nonnegative sqft area. Include availability changes and known/unknown deletions. No caller can replace the manifest, append changes or rotate its generation.

A factory binds a detached validated FeedContext to this registered profile. Each read verifies that exact context and closed bounded input: limit1–100, overlapSeconds0–86400, canonical UTC/null watermark and opaque/null cursor<=8192UTF8 bytes. A watermark later than the immutable completed watermark denies rather than guessing. On a new cycle, select entries by fixed observedAt after the watermark minus overlap; a continuation preserves the exact original selection and options. Cursor identity binds context, generation, watermark, overlap and limit. Treat cursors as opaque tokens matched against the source's server-owned page boundaries, never as caller-supplied offsets or source-order evidence. Restart reconstructs the same manifest, page boundaries and proof; cloning an adapter or retrying a page must not mint new source identities, ingestion or expiry.

The detached frozen ChangePage and its proof have a canonical own-data SHA-256 pageDigest including all page clocks and preserving array order. Proof binds context/profile/generation and exactly one index/changeId/sequence per operation. Relational checks require matching entry indices, unique identities/sequences, the current registered generation and the exact page digest. Empty completed pages have zero proof entries. Proof contains no credential, raw provider data or cursor details. A source proof is server-local content evidence, not permission, authenticity for arbitrary callers, current feed rights or a page persistence receipt.

W07 may implement only new packages/mls/ordered-source.ts, its immutable synthetic fixture asset and targeted pure tests after these shared prerequisites are committed. Do not change the existing adapter, replication helper, packages exports, SQL, roles, source configuration or runtime registration without coordination. Tests must prove process/factory restart stability, continuation replay, context/options/cursor tampering denial, fixed clock/freshness preservation, tied/null source times and deletion identities, closed bounded own-data/hook safety and schema/digest binding. The next persistence step still requires coordinator-reviewed ledgers, current actor/feed rights, guarded grants/fencing and atomic receipt/checkpoint/outbox acceptance. Never interpret this fixture manifest as live Trestle or MLS policy evidence.
