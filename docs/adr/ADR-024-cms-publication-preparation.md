# ADR-024 — Synthetic CMS publication preparation

Accepted bounded MOD-C-003/004 prerequisite on2026-10-10, following the reviewed W05 publication-boundary proposal. This decision authorizes pure detached content validation and complete HTML preparation, not publishing, jobs, anonymous reads, host provisioning or new database privileges. The frozen PublishRequest, Site, Document, Revision and Seo shapes remain generated; the internal input/output declaration is packages/contracts/internal/cms-publication-preparation.ts.

The first preparation supports registered schema-v1 hero/text/CTA/footer and the exact repository template theme version. All input must be closed bounded plain own-data JSON detached before validators, hashes or rendering; inherited/accessor/toJSON hooks, proxies, sparse arrays, cycles and unsupported values cannot execute. Nested unsupported blocks, media, forms, MLS/search/maps, social assets and unsafe links fail the whole preparation while existing private revision recovery remains intact. Author text is escaped, never hydrated from private profiles or provider records.

The command revision must match the supplied revision and document; document.siteId must match the site. ExpectedDocumentVersion must equal the current safe positive document version and have a representable successor. Suspended/publishing sites deny. The revision's canonical schemaVersion/blocks/seo hash must equal its supplied stored hash. This proves consistency of a supplied snapshot, not its current authorization or authenticity; a later transactional command must acquire and recheck its own current sources.

Synthetic target and approved link origins are exact canonical HTTPS origins under example.test, with no userinfo, path/query/fragment, nondefault port, trailing-dot/encoded/ambiguous authority or IP. These are test fixtures, never a Browser Block workaround, DNS/TLS proof or routable production binding. BindingVersion is a positive safe integer. Policy code and renderer version are exact platform constants; the bounded sorted unique origin set is frozen and included in policyHash. Unknown policy or theme versions deny without fallback.

The route is derived from the current document slug: bounded lowercase alphanumeric/hyphen path segments, no empty/dot/encoded/query/fragment segments and no reserved API/dev/staff/preview routes. CanonicalPath, if supplied, must exactly match this route. Freeze title/kind/route/theme/SEO/contentHash/policyHash/target generation together. Emit a complete semantic escaped HTML document with a visibly synthetic marker, canonical/SEO/noindex tags, pinned platform styling and restrictive script-free CSP. Header projection is no-store, nosniff and no-referrer. Never embed executable author content or fetch remote assets. HTML is bounded to1MiB and has its own SHA-256. Output contains no business profile, raw revision JSON, credentials or session information.

W05 may implement packages/cms/publication-preparation.ts and targeted tests after this shared declaration is committed. It does not change existing draft services, registry contracts, migrations, dependencies or routes without coordination. If safe reuse of the existing renderer requires a shared serializer fix, propose it to the coordinator first. Publication persistence, requester-only Job202 polling, fenced worker execution, current profile eligibility, exact host routing, anonymous RLS context, content-revision rollback and durable invalidation remain separate prerequisites. The proposal's content-only rollback interpretation is accepted as the initial direction; no rollback command is implemented by this helper. M3 completion and browser/device/public hosting gates remain open.
